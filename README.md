## Projeto em destaque

### monitor-db-ia
Monitoramento de bancos com IA, do alerta à correção comprovada. Detecta queries lentas no PostgreSQL e
no Oracle, gera o diagnóstico com IA local, abre o chamado no Jira, avisa no Slack e, depois da aprovação
do DBA, cria o índice, mede o ganho e resolve o chamado. O histórico vai para o Databricks, que prevê
quais queries vão estourar o limite.

`97% de ganho em query real do lab` · `PostgreSQL + Oracle` · `n8n` · `Ollama` · `Jira` · `Databricks` · `Power BI`
